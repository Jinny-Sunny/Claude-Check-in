# Team Log In — เว็บเช็คชื่อคลาส 9 โมง

เว็บเช็คชื่อออนไลน์ ใช้ **Supabase** เก็บข้อมูลและจัดการล็อกอิน (โปรเจกต์ `TeamLogInCheck`, ภูมิภาคสิงคโปร์)

## ไฟล์ในโปรเจกต์
| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด (ล็อกอิน, เช็คชื่อ, หน้าแอดมิน) |
| `roster.csv` | รายชื่อผู้เข้าเรียน (อ้างอิง) |
| `CHANGELOG.md` | ประวัติเวอร์ชัน |

## วิธีใช้
**แอดมิน**
1. ล็อกอินด้วยบัญชีแอดมิน
2. แท็บ **ตั้งค่า** — ยืนที่บริษัท กด "ใช้ตำแหน่งที่ฉันยืนอยู่" → บันทึก (รัศมี 300 ม., เวลาเข้าคลาส 09:00)
3. แท็บ **รายชื่อ** — เพิ่มสมาชิก (ชื่อ, username, รหัสผ่าน) หรือนำเข้า CSV 3 คอลัมน์: `ชื่อ,username,รหัสผ่าน`
4. แท็บ **QR Code** — พิมพ์ติดหน้าห้อง
5. แท็บ **วันนี้ / ย้อนหลัง** — ดูใครมา ตรงเวลา/สาย และดาวน์โหลด CSV

**สมาชิก**
สแกน QR → ล็อกอินด้วย username/รหัสผ่านที่ได้รับ → กด "เช็คชื่อ" (ต้องเปิด Location และอยู่ในรัศมี)

## หมายเหตุ
- username ใช้ได้เฉพาะ a-z, 0-9, `. _ -` (ช่องว่างจะถูกตัดออกอัตโนมัติ)
- ลืมรหัสผ่าน: แอดมินกดปุ่ม "รหัส" ข้างชื่อในแท็บรายชื่อเพื่อตั้งใหม่
- ระยะ 300 ม. และการเช็คได้วันละครั้งตรวจที่ฝั่งเซิร์ฟเวอร์ (Supabase)
- คีย์ที่อยู่ใน `index.html` เป็น publishable key ใส่ในเว็บได้ ข้อมูลถูกป้องกันด้วย Row Level Security

## การแก้เวอร์ชัน
แก้ `APP_VERSION` ใน `index.html` และเพิ่มรายการใน `CHANGELOG.md` ทุกครั้งที่ปรับเว็บ
