# เว็บเช็คชื่อทีม 9 โมง

เว็บเช็คชื่อผู้เข้าเรียนรายวัน (เริ่มเรียน 09:00 น.) บันทึกลง **Google Sheet** อัตโนมัติ เปิดจากหลายเครื่องก็เห็นข้อมูลชุดเดียวกัน

เช็คชื่อได้ 2 แบบ
- **ผู้ดูแลกดให้** ในแท็บ "เช็คชื่อ"
- **น้องสแกน QR เอง** ระบบตรวจว่าอยู่ห่างบริษัทไม่เกิน 300 เมตรก่อนบันทึก

## ในโฟลเดอร์นี้มีอะไรบ้าง

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บเช็คชื่อ (ไฟล์เดียวจบ) |
| `config.js` | ใส่ลิงก์ Google Sheet (Web app URL) ที่นี่ |
| `Code.gs` | โค้ดที่วางใน Google Sheet เพื่อรับข้อมูลจากหน้าเว็บ |
| `roster.csv` | รายชื่อผู้เข้าเรียน 22 คน (ใช้นำเข้าในหน้าเว็บได้) |

## ขั้นที่ 1 — ติดตั้งตัวรับข้อมูลใน Google Sheet

Sheet ที่ใช้ต้องมีแท็บ **Roster** (id, ชื่อ-นามสกุล, หน่วยงาน, ชื่อภาษาอังกฤษ), **Attendance** และ **Settings** (key / value) ถ้ายังไม่มี โค้ดจะสร้างให้

1. เปิด Google Sheet แล้วไปที่เมนู **ส่วนขยาย (Extensions) › Apps Script**
2. ลบโค้ดเดิมทั้งหมด วางโค้ดจาก `Code.gs` แล้วกดบันทึก
3. เลือกฟังก์ชัน **`setup`** แล้วกด **Run** (ไม่ลบข้อมูลเดิม แค่เพิ่มคอลัมน์และค่าตั้งค่าที่ขาด)
   - Google จะขอสิทธิ์ ให้กด *Review permissions* › เลือกบัญชี › *Advanced* › *Go to … (unsafe)* › *Allow*
4. กด **Deploy › New deployment** › รูปเฟือง › **Web app**
   - *Execute as*: **Me**
   - *Who has access*: **Anyone**
   - กด **Deploy** แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

## ขั้นที่ 2 — เชื่อมหน้าเว็บกับ Google Sheet

เปิดไฟล์ `config.js` แล้ววาง URL ที่คัดลอกมา

```js
window.ATTENDANCE_CONFIG = {
  SCRIPT_URL: "https://script.google.com/macros/s/xxxxxxxx/exec",
  KEY: "",
  REFRESH_SECONDS: 30
};
```

ลองเปิด `index.html` ในเบราว์เซอร์ มุมขวาบนควรขึ้นว่า **"ซิงก์กับ Google Sheet แล้ว"**

## ขั้นที่ 2.5 — ตั้งตำแหน่งบริษัทสำหรับสแกน QR

1. เปิดหน้าเว็บ ไปที่แท็บ **"รายชื่อ & ตั้งค่า"** หัวข้อ **ตำแหน่งบริษัท**
2. ใส่พิกัดได้ 2 วิธี
   - เปิด Google Maps กดค้างที่ตึกบริษัท (บนคอมพิวเตอร์ให้คลิกขวา) คัดลอกตัวเลข เช่น `13.7563, 100.5018` แล้ววางในช่อง **ละติจูด** ระบบจะแยกให้เอง
   - หรือไปยืนที่บริษัทแล้วกด **"ใช้ตำแหน่งที่อยู่ตอนนี้"**
3. ตั้งรัศมี (ค่าเริ่มต้น 300 เมตร) แล้วกด **บันทึกตำแหน่ง** ค่าจะไปอยู่ในแท็บ **Settings** ของ Sheet

## ขั้นที่ 3 — เอาขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (ให้ `index.html` อยู่ชั้นบนสุด)
3. ไปที่ **Settings › Pages** › *Source*: **Deploy from a branch** › เลือก `main` และ `/ (root)` › **Save**
4. รอประมาณ 1–2 นาที จะได้ลิงก์รูปแบบ `https://ชื่อผู้ใช้.github.io/ชื่อrepo/`

## ใช้งาน QR เช็คชื่อทุกเช้า

1. เปิดแท็บ **"QR เช็คชื่อ"** แล้วกด **แสดงเต็มจอ** หรือ **พิมพ์** ติดหน้าห้อง
2. น้องสแกนด้วยกล้องมือถือ › เลือกชื่อตัวเอง (ครั้งต่อไปมือถือจำให้) › กด **เช็คชื่อ** › อนุญาตให้ใช้ตำแหน่ง
3. ถ้าอยู่ในระยะ ระบบจะบันทึกเวลาลง Sheet ทันที ถ้าอยู่ไกลเกินจะบอกว่าห่างกี่เมตร

กันการโกงไว้อย่างไร
- **QR เปลี่ยนทุกวัน** ถ้าถ่ายรูป QR ไว้ จะเอาไปใช้วันอื่นไม่ได้
- **Google Sheet เป็นผู้ตรวจ** ทั้งวันที่ ระยะห่าง และเวลาเข้า (ใช้เวลาของเซิร์ฟเวอร์ ไม่ใช่เวลาในมือถือ)
- ถ้าสัญญาณ GPS คลาดเคลื่อนเกิน 150 เมตร ระบบจะให้ลองใหม่
- ถ้าน้องเช็คชื่อไปแล้ว การสแกนซ้ำจะไม่เปลี่ยนเวลาเดิม

ข้อจำกัด: แอปปลอมตำแหน่ง GPS บางตัวยังหลอกระบบได้ ใช้ระบบนี้เป็นการกันขั้นพื้นฐาน และควรให้ผู้ดูแลดูในห้องประกอบด้วย การสแกนต้องเปิดผ่าน `https://` (GitHub Pages เป็น https อยู่แล้ว) ถ้าเปิดไฟล์จากเครื่องโดยตรง มือถือจะไม่ยอมให้ใช้ตำแหน่ง

## ข้อมูลใน Google Sheet

แต่ละครั้งที่มีคนกดเช็คชื่อ จะได้ 1 แถวในแท็บ **Attendance**

| วันที่ | id | ชื่อ-นามสกุล | หน่วยงาน | เวลาเช็คอิน | สถานะ | สาย (นาที) | บันทึกเมื่อ (ISO) | … | วิธีเช็คชื่อ | ระยะห่าง (ม.) |
|---|---|---|---|---|---|---|---|---|---|---|
| 2026-11-17 | a01 | ภณธกร วงศ์เจริญ | เบทาโกร | 08:52 | มาตรงเวลา | | 2026-11-17T08:52:00+07:00 | | สแกน QR | 95 |
| 2026-11-17 | a02 | วิภาดา พลาธนพร | Foodle Noodle Co., Ltd. | 09:20 | มาสาย | 5 | 2026-11-17T09:20:00+07:00 | | ผู้ดูแล | |

- ถ้ากดเปลี่ยนสถานะของคนเดิมในวันเดียวกัน ระบบจะแก้แถวเดิม ไม่สร้างแถวซ้ำ
- ถ้ากด "ล้าง" แถวนั้นจะถูกลบ
- คอลัมน์ "สถานะ" ใช้คำว่า มาตรงเวลา / มาสาย / ลา / ขาด ถ้าแก้ใน Sheet เอง ให้ใช้คำเหล่านี้ (หรือ มา / สาย)
- ย้ายตำแหน่งคอลัมน์ได้ แต่อย่าเปลี่ยนชื่อหัวคอลัมน์
- แก้รายชื่อได้ทั้งจากหน้าเว็บ (แท็บ "รายชื่อ & ตั้งค่า") และแก้ในแท็บ **Roster** ของ Sheet โดยตรง

## เรื่องที่ควรรู้

- **ถ้าแก้โค้ดใน `Code.gs`** ต้องกด **Deploy › Manage deployments ›** ไอคอนดินสอ › *Version*: **New version** › **Deploy** ทุกครั้ง ไม่อย่างนั้นเว็บจะยังใช้โค้ดเก่า
- **ถ้าอินเทอร์เน็ตหลุด** หน้าเว็บจะจำรายการที่ยังส่งไม่ได้ไว้ แล้วส่งให้เองเมื่อกลับมาออนไลน์
- **หน้าผู้ดูแลกับหน้าสแกนเป็นไฟล์เดียวกัน** ถ้าน้องลบ `?scan=…` ออกจากลิงก์ ก็จะเห็นหน้าผู้ดูแลได้ ถ้าอยากล็อกหน้าผู้ดูแล บอก Claude ให้เพิ่มรหัสผ่านได้
- **ความปลอดภัย** ใครที่มีลิงก์ Web app ก็ส่งข้อมูลเข้า Sheet ได้ ถ้าต้องการกันขั้นพื้นฐาน ให้ตั้ง `API_KEY` ใน `Code.gs` และใส่ค่าเดียวกันใน `KEY` ของ `config.js` (รหัสนี้ยังมองเห็นได้ในซอร์สของหน้าเว็บ)
- อย่าใส่ข้อมูลส่วนตัว เช่น เบอร์โทรหรืออีเมล ลงใน repository ที่เป็น Public
- ถ้าเว้น `SCRIPT_URL` ว่างไว้ เว็บจะเก็บข้อมูลไว้ในเบราว์เซอร์ของเครื่องที่เปิดเท่านั้น

## เวอร์ชัน

เลขเวอร์ชันแสดงข้างชื่อเว็บและท้ายหน้า กดที่เลขเวอร์ชันเพื่อดู [ประวัติเวอร์ชัน](CHANGELOG.md) ได้

เวลาออกเวอร์ชันใหม่
1. แก้ `APP_VERSION` และ `APP_DATE` ใน `index.html`
2. ถ้าแก้ `Code.gs` ให้แก้ `SCRIPT_VERSION` ด้วย และถ้าหน้าเว็บต้องใช้โค้ด Sheet เวอร์ชันใหม่ ให้แก้ `MIN_SCRIPT_VERSION` ใน `index.html`
3. เพิ่มรายการใน `CHANGELOG.md`

ท้ายหน้าเว็บจะบอกเวอร์ชันของโค้ดใน Google Sheet ถ้าขึ้นตัวอักษรสีส้ม แปลว่ายังไม่ได้ Deploy โค้ดเวอร์ชันใหม่
